# Serial captures and protocol vectors

> Everything here is SYNTHETIC or third-party published data **except files starting with `real-`**, which
> were captured from the owner's F730 and state device, firmware, date, method and sanitisation in their header.

| File | Kind | Provenance |
|---|---|---|
| `protocol-vectors.synthetic.json` | 22 single-frame vectors with expected decode/reply | Generated by `docs/research/tools/nibe_ref.py gen fixtures/serial-captures`. Each vector has `kind` (`synthetic`, `third_party_published`, `documented_from_source`), `provenance` and `rule_status`. Third-party bytes come from yozik04/nibe tests (GPL-3.0, real bus data from *other* NIBE models) and the openHAB NibeGW test stream (EPL-2.0); NibePi start-up writes come from anerdins/nibepi `backend.js:37` (MIT). |
| `synthetic-f730-session.capture.jsonl` | Timeline of a short bus session (rx/tx bytes with µs timestamps) | Same generator. Values, product string (`F730 CU 3x400V`), firmware (1234) and **all timings are invented**. |
| `real-f730-passive-2026-10-24.capture.jsonl` | 60 s receive-only capture from the owner's F730 (`F730 Cu 3x400V`, product-info version 9721), no accessory answering | Recorded on the bench Pi (Waveshare HAT, `/dev/ttyAMA0`), nothing transmitted. Tokens 0x69/0x6B at 1.0 s, empty LOG.SET 0x68 frames every 3.1 s, 0x6D every 6 s, 0xEE to 0x20 every 1.5 s. Checked by `crates/device-f730/tests/replay.rs`. |
| `real-f730-reads-2026-10-24.capture.jsonl` | Last ~71 s of HP-26 run 1 on the owner's F730: gateway ACKs plus one read session (8 registers) | Gateway wire recorder with `--allow-hardware-reads`. Replies and decoded values (48852=0 high word first, BT1 9.6 °C, heat offset −2, …) are asserted in `crates/device-f730/tests/replay.rs` (M2 acceptance). |
| `synthetic-f730-session.expected.json` | Expected counters and decoded values for the session | Same generator; counters are derived from the timeline and cross-checked against the reference reply logic. Assumes word swap 48852 = 1. |

## Formats
`capture-jsonl` v1 (bump `version` if incompatible):
```
line 1: {"format":"nibe-gateway/capture-jsonl","version":1,"synthetic":true|false,"device":...,"serial":"9600 8N1","provenance":...}
then:   {"t_us": <monotonic µs>, "dir": "rx"|"tx", "hex": "<bytes exactly as on the wire, escaped>"}
```
`rx` = bytes read from the bus (pump and other accessories), `tx` = bytes we wrote. Chunks need not align
with frames (a real recorder writes whatever `read()` returned).

`protocol-vectors` v1: `{format, version, contains_captures_from_our_f730:false, vectors:[{name, kind,
direction, hex, expect{...}, rule_status, provenance}]}`. `expect.reply` is the byte(s) a read-only MODBUS40
emulation must send (`"06"`, `"15"`, or `null` = stay silent).
