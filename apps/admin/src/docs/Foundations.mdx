# Colours

The palette is 32 tokens in `src/ui/foundations/tokens.css` with 31 literal values (28 opaque
colours, 3 white overlays for the dark banner), plus four chart series colours. Component CSS uses
these, apart from one chart shadow; **Foundations / Palette audit** checks hex literals live. Every text token meets WCAG AA (4.5:1) on every
surface it is used on.

## History

Before 2026-10-27 the stylesheet had 115 distinct colours: nine greys for "muted text" alone, a dozen
hairline borders and about twenty off-white tints, most of them failing contrast. They were merged
by role into the tokens above; layout did not change.
