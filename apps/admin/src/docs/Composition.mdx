# Composition map

How every screen is assembled. Each line is a component from `src/ui` (or a domain component from
`src/pages`); indentation is containment. These are the component boundaries the app now uses.

```
│   └── MetricCard ×3 ── MetricLabel · MetricValue(tone) · MetricDetail
├── Columns
│   ├── Panel "Live snapshot"  [action: InlineLink]

│   └── Panel "Gateway details"
│       └── FactList ── Fact ×6
└── QuietNote
```
