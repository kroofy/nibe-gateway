Fault injection: full observation channel and blocked application executor do
not delay wire replies; one deadline miss is tolerated and the next successful
reply resets its streak; four consecutive misses stop a default-policy fake
transport. Injected send error is fatal without a hardware reopen path. Real
Linux PTY EOF/EIO causes HTTP 503/recovering, successful reopen resumes ACKs and
readiness, and permanent unplug exhausts retries and exits nonzero. Fallback
checks actual PTY frame age against a shortened test threshold and fake-systemctl
stop/start order. Failed gateway stop never starts legacy. Supervisor tests cover
unrequested exit 0 → 1, exit 7 → 7, signal exit → 143, requested stop → 0.

Final soak evidence: [WS09-soak.json](WS09-soak.json), **180 seconds**, simulated

These are host Linux debug/synthetic results, not Pi footprint or timing evidence.
